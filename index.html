Mô hình ERD: Quản lý đơn đặt hàng

Hoàn thành bài thực hành thiết kế, chuẩn hóa mô hình thực thể liên kết (ERD) và chuyển đổi sang sơ đồ cơ sở dữ liệu quan hệ hoàn chỉnh.

🧭 Tổng quan phương pháp thiết kế từ bài toán thực tế

Quy trình thiết kế mô hình dữ liệu đi từ phân tích nghiệp vụ thực tế (chứng từ đơn đặt hàng và phiếu giao hàng), xác định thực thể, thuộc tính, phân tích bản số quan hệ và chuẩn hóa cấu trúc để loại bỏ dư thừa.

Bước 1

Liệt kê & Chọn lọc thông tin

  • Đơn đặt hàng: Số ĐH, Tên ĐV, Địa chỉ, Điện thoại, Ngày đặt, Tên hàng, Mô tả, Đv tính, Số lượng, Người đặt.
  • Phiếu giao hàng: Số PG, Tên ĐV, Địa chỉ, Nơi giao hàng, Ngày giao, Tên hàng, Đv tính, Số lượng, Đơn giá, Thành tiền, Người nhận, Người giao.
Bước 2

Xác định thực thể & Thuộc tính

  • ĐƠN VỊ ĐH: Mã ĐV, Tên ĐV, Địa chỉ, Điện thoại.
  • ĐƠN VỊ KH: Mã ĐV, Tên ĐV, Địa chỉ.
  • HÀNG: Mã hàng, Tên hàng, Đv tính, Mô tả.
  • NGƯỜI ĐẶT: Mã số NĐ, Họ tên NĐ.
  • NƠI GIAO: Mã số ĐĐG, Tên nơi giao.
  • NGƯỜI NHẬN & NGƯỜI GIAO: Mã số và Họ tên.
  • ĐƠN ĐH & PHIẾU GH: Số chứng từ, Ngày lập.
Bước 3

Xác định các mối quan hệ

  • Người đặt THUỘC Đơn vị đặt hàng (1 - N).
  • Người nhận THUỘC Đơn vị khách hàng (1 - N).
  • Người đặt LẬP Đơn đặt hàng (1 - N).
  • Đơn hàng GỒM Hàng (N - N, thuộc tính Số lượng).
  • Người giao GIAO Phiếu giao (1 - N).
  • Phiếu giao GIAO TẠI Nơi giao (N - 1).
  • Phiếu giao GỒM Hàng (N - N, SL, Đơn giá, Thành tiền).
Bước 4

Vẽ sơ đồ ERD ban đầu

  • Mô hình hóa toàn bộ 9 thực thể ban đầu.
  • Thể hiện các mối liên kết và bản số (1-1, 1-N, N-N).
  • Giữ nguyên quan hệ nhiều-nhiều có thuộc tính quan hệ (Số lượng đặt, Đơn giá giao, Thành tiền).
Bước 5

Chuẩn hóa & Rút gọn mô hình

  • Gộp thực thể: ĐƠN VỊ ĐH và ĐƠN VỊ KH có chung ngữ nghĩa khách hàng bên ngoài → Gộp thành ĐƠN VỊ KHÁCH.
  • Khử quan hệ N-N: Tách quan hệ Nhiều - Nhiều thành 2 bảng liên kết: CHI_TIET_DON_HANG và CHI_TIET_PHIEU_GIAO.

💻 Mã nguồn kịch bản SQL (database.sql)

MySQL 8.0+ / MariaDB • DDL & DML Schema 
-- Tạo cơ sở dữ liệu
CREATE DATABASE IF NOT EXISTS quan_ly_don_hang CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE quan_ly_don_hang;

-- 1. Bảng ĐƠN VỊ KHÁCH
CREATE TABLE don_vi_khach (
    ma_dv VARCHAR(20) NOT NULL PRIMARY KEY,
    ten_dv VARCHAR(150) NOT NULL,
    dia_chi VARCHAR(255) NOT NULL,
    dien_thoai VARCHAR(20)
);

-- 2. Bảng NGƯỜI ĐẶT
CREATE TABLE nguoi_dat (
    ma_nd VARCHAR(20) NOT NULL PRIMARY KEY,
    ho_ten_nd VARCHAR(100) NOT NULL,
    ma_dv VARCHAR(20) NOT NULL,
    CONSTRAINT fk_nguoidat_donvikhach FOREIGN KEY (ma_dv) REFERENCES don_vi_khach(ma_dv)
);

-- 3. Bảng NGƯỜI NHẬN
CREATE TABLE nguoi_nhan (
    ma_nn VARCHAR(20) NOT NULL PRIMARY KEY,
    ho_ten_nn VARCHAR(100) NOT NULL,
    ma_dv VARCHAR(20) NOT NULL,
    CONSTRAINT fk_nguoinhan_donvikhach FOREIGN KEY (ma_dv) REFERENCES don_vi_khach(ma_dv)
);

-- 4. Bảng NGƯỜI GIAO
CREATE TABLE nguoi_giao (
    ma_ng VARCHAR(20) NOT NULL PRIMARY KEY,
    ho_ten_ng VARCHAR(100) NOT NULL
);

-- 5. Bảng NƠI GIAO
CREATE TABLE noi_giao (
    ma_ddg VARCHAR(20) NOT NULL PRIMARY KEY,
    ten_noi_giao VARCHAR(255) NOT NULL
);

-- 6. Bảng HÀNG
CREATE TABLE hang (
    ma_hang VARCHAR(20) NOT NULL PRIMARY KEY,
    ten_hang VARCHAR(150) NOT NULL,
    dv_tinh VARCHAR(50) NOT NULL,
    mo_ta_hang TEXT
);

-- 7. Bảng ĐƠN ĐẶT HÀNG
CREATE TABLE don_dat_hang (
    so_dh VARCHAR(20) NOT NULL PRIMARY KEY,
    ngay_dat DATE NOT NULL,
    ma_nd VARCHAR(20) NOT NULL,
    CONSTRAINT fk_dondat_nguoidat FOREIGN KEY (ma_nd) REFERENCES nguoi_dat(ma_nd)
);

-- 8. Bảng CHI TIẾT ĐƠN HÀNG
CREATE TABLE chi_tiet_don_hang (
    so_dh VARCHAR(20) NOT NULL,
    ma_hang VARCHAR(20) NOT NULL,
    so_luong_dat INT NOT NULL CHECK (so_luong_dat > 0),
    PRIMARY KEY (so_dh, ma_hang),
    FOREIGN KEY (so_dh) REFERENCES don_dat_hang(so_dh),
    FOREIGN KEY (ma_hang) REFERENCES hang(ma_hang)
);

-- 9. Bảng PHIẾU GIAO HÀNG
CREATE TABLE phieu_giao_hang (
    so_pg VARCHAR(20) NOT NULL PRIMARY KEY,
    ngay_giao DATE NOT NULL,
    so_dh VARCHAR(20) NOT NULL,
    ma_ng VARCHAR(20) NOT NULL,
    ma_nn VARCHAR(20) NOT NULL,
    ma_ddg VARCHAR(20) NOT NULL,
    FOREIGN KEY (so_dh) REFERENCES don_dat_hang(so_dh),
    FOREIGN KEY (ma_ng) REFERENCES nguoi_giao(ma_ng),
    FOREIGN KEY (ma_nn) REFERENCES nguoi_nhan(ma_nn),
    FOREIGN KEY (ma_ddg) REFERENCES noi_giao(ma_ddg)
);

-- 10. Bảng CHI TIẾT PHIẾU GIAO
CREATE TABLE chi_tiet_phieu_giao (
    so_pg VARCHAR(20) NOT NULL,
    ma_hang VARCHAR(20) NOT NULL,
    so_luong_giao INT NOT NULL CHECK (so_luong_giao > 0),
    don_gia_giao DECIMAL(15, 2) NOT NULL CHECK (don_gia_giao >= 0),
    thanh_tien DECIMAL(15, 2) GENERATED ALWAYS AS (so_luong_giao * don_gia_giao) STORED,
    PRIMARY KEY (so_pg, ma_hang),
    FOREIGN KEY (so_pg) REFERENCES phieu_giao_hang(so_pg),
    FOREIGN KEY (ma_hang) REFERENCES hang(ma_hang)
);
